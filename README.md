# ثلاثاء الوفاء

صفحة سردية عربية توثق ذكرى ٦ أيلول ٢٠١١ بمشاهد وصور وتفاعلات أثناء التمرير.

**الموقع المنشور:** https://kakramah.github.io/tuesday-of-loyalty/

هذا الموقع منشور، لكنه غير مدرج حالياً في فهرس الأعمال الرئيسي؛ إبقاء هذا التمييز مقصود حتى يُحسم ترتيب النسخ المتقاربة تحريرياً.

## بنية المشروع

- `index.html`: النص والمشاهد.
- `style.css`: التصميم والحركة والاستجابة.
- `script.js`: سلوك التصفح والتفاعل.
- `images/` و`fonts/`: الأصول المستخدمة.

## المعاينة والتعديل

من جذر المستودع:

```sh
python3 -m http.server 8000
```

افتح `http://localhost:8000/`، ثم راجع تسلسل المشاهد والصور والتصفح على الهاتف والحاسوب قبل الدمج. لا توجد خطوة بناء في جذر المستودع.
